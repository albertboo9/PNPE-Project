# PNPE 360

## Plateforme numérique de la Pépinière Nationale Pilote d’Entreprises d’Edéa

### Dossier de spécifications produit, fonctionnelles, UX/UI et scénario de démonstration

**Version : Prototype de présentation stratégique**

---

# 1. OBJET DU DOCUMENT

Ce document constitue la bible de référence pour la conception et l'implémentation du prototype **PNPE 360**.

Le prototype doit matérialiser une vision numérique crédible, moderne et immédiatement compréhensible de la transformation digitale de la **Pépinière Nationale Pilote d'Entreprises d'Edéa (PNPE)**.

Il ne s'agit pas de produire une simple refonte graphique du StarterKit CM.

Il ne s'agit pas non plus de reproduire le prototype BSTPKIT avec une nouvelle palette de couleurs.

Il s'agit de construire une **verticalisation métier complète de l'écosystème PNPE**, en réutilisant les fondations UX, techniques et visuelles éprouvées du prototype précédent, mais en les adaptant aux missions réelles de la PNPE.

Le résultat doit permettre à un dirigeant de la PNPE de comprendre en quelques minutes :

- ce que devient la PNPE grâce au numérique ;
- comment les porteurs de projets sont recrutés ;
- comment ils sont évalués ;
- comment ils sont formés ;
- comment leurs projets sont incubés ;
- comment ils sont accompagnés ;
- comment leur progression est suivie ;
- comment les opportunités de financement sont identifiées ;
- comment les projets matures sont valorisés ;
- comment les entreprises peuvent être exposées à des donneurs d'ordre et partenaires ;
- comment la PNPE mesure son impact ;
- et comment l'ensemble du parcours peut être centralisé dans une plateforme unique.

# 2. POSITIONNEMENT PRODUIT

## 2.1 Vision

PNPE 360 doit être présenté comme :

> **Le parcours entrepreneurial numérique de la PNPE d'Edéa, de l'idée à l'entreprise.**

La plateforme doit transformer un accompagnement aujourd'hui dispersé entre candidatures, formations, échanges, documents, accompagnement humain, incubation et suivi en une expérience numérique continue.

# 3. RÉALITÉ INSTITUTIONNELLE À RESPECTER

La PNPE d'Edéa est une structure publique opérationnelle d'appui à l'essor du secteur privé à travers l'innovation et la créativité, sous tutelle du MINPMEESA.

Sa documentation institutionnelle la positionne comme une plateforme de référence au service de l'innovation, de la créativité et du développement des entreprises.

Ses missions couvrent notamment :

- l'accueil ;
- la formation ;
- l'accompagnement ;
- l'identification et la valorisation du potentiel entrepreneurial ;
- la détermination des besoins d'accompagnement ;
- l'incubation ;
- le suivi des entreprises incubées ;
- la qualification de la faisabilité économique et industrielle des projets ;
- l'assistance administrative ;
- le soutien technique ;
- le soutien d'affaires ;
- la finance et la comptabilité ;
- la commercialisation ;
- la productivité ;
- la qualité ;
- le prototypage ;
- le packaging ;
- le réseautage ;
- la mutualisation ;
- l'information sur les opportunités d'affaires.

La PNPE est historiquement structurée autour de quatre grandes composantes :

1. Centre de formation ;
2. Incubateur d'entreprises ;
3. Pépinière d'entreprises ;
4. Centre des Formalités de Création des Entreprises.

Le prototype doit respecter cette logique.

# 55. ARCHITECTURE DU PROTOTYPE

Même si le prototype ne possède pas de backend complet, le code doit être structuré comme si le produit devait évoluer vers une application réelle.

Séparer :

```text

pages/
layouts/
stores/

```

Ne jamais disperser les objets de démonstration directement dans les composants.

# 56. MODE DÉMONSTRATION

Prévoir un environnement de démonstration déterministe.

L'objectif est que le présentateur puisse reproduire exactement le scénario.

```text

↓
```

Aucun écran ne doit dépendre d'un appel externe pour fonctionner pendant la démonstration.

# 62. DIRECTIVE FINALE À L'AGENT IA

Tu n'es pas chargé de produire une simple interface administrative.

Tu dois construire une **représentation numérique crédible de la PNPE de demain**.

Comprends d'abord le métier.

Respecte ensuite les processus.

Puis construis l'expérience.

Le code est le moyen.

Le produit est le parcours.

Le prototype doit donner aux dirigeants de la PNPE la capacité de se projeter immédiatement dans une organisation où :

- les candidatures sont centralisées ;
- les porteurs sont évalués ;
- les formations sont accessibles en ligne ;
- les parcours sont suivis ;
- les certificats sont valorisés ;
- les agents disposent d'une vision opérationnelle ;
- les projets sont structurés ;
- les projets matures sont visibles ;
- les opportunités sont distribuées ;
- le financement est préparé ;
- les entreprises sont suivies après incubation ;
- et la Direction dispose d'une vision consolidée de l'impact de la PNPE.

**Ne cherche pas à faire beaucoup de fonctionnalités.**

Cherche à faire comprendre beaucoup de valeur avec peu d'interactions.

Le prototype doit être suffisamment spectaculaire pour impressionner, mais suffisamment réaliste pour être crédible.

Il doit raconter une seule histoire :

> **De l'idée à l'entreprise, la PNPE accompagne, structure, forme, finance et fait grandir.**
